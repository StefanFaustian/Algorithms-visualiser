# Algorithms visualiser

A clean and interactive web application built with React to visualize how different pathfinding algorithms work under the hood.

## Implemented algorithms
* **Dijkstra's Algorithm**: The classical pathfinding algorithm - guarantees the shortest path.
* **A\* Search**: Uses heuristics to guarantee the shortest path much faster than Dijkstra.
* **Breadth-First Search (BFS)**: Explores equally in all directions; guarantees the shortest path on an unweighted grid.
* **Depth-First Search (DFS)**: Explores as far as possible along each branch before backtracking; does *not* guarantee the shortest path.

## Features
* **Left-Click (Hold & Drag):** Draw walls/obstacles on the grid.
* **Shift + Left-Click (Hold & Drag):** Erase walls.
